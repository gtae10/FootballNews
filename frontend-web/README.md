# Frontend Web

해외축구 뉴스 번역 앱 "433"의 React 웹 클라이언트입니다.

## 실행 방법 (예정)

```bash
npm install
npm run dev
```

백엔드 API 서버(`backend/`)가 `http://localhost:8080`에서 실행 중이어야 합니다.

## 게스트 모드 (개발 편의용)

로그인 페이지에 "게스트로 둘러보기" 버튼이 있다. Google OAuth 자격증명(`backend/.env`의
`GOOGLE_CLIENT_ID`/`SECRET`) 없이도 피드/검색/기사 상세/루머 타임라인처럼 인증이 필요 없는
화면을 확인할 수 있게 하기 위한 것이다(`AuthContext`의 `isGuest` 상태, 프론트엔드에서만
동작하고 백엔드 변경은 없다). 설정 페이지, 관심 구단 저장, 기자 제보처럼 로그인이 실제로
필요한 기능은 게스트 상태에서 안내 메시지와 함께 막힌다.

**실서비스로 나가기 전에 검토 필요**: 이 버튼은 어디까지나 개발 중 편의 기능이다. 실제
사용자에게 노출할지, 없애거나 숨길지 배포 전에 결정해야 한다.
