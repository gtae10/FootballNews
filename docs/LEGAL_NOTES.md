# 저작권 / 법적 고려사항

- 기사 전문을 그대로 번역해 게시하면 저작권 침해 소지가 있습니다.
  - 전문 번역 대신 핵심 요약 + 번역을 제공하는 방식을 권장합니다.
  - 항상 원문 링크와 출처(매체명)를 명시합니다.
- 크롤링 전 각 사이트의 `robots.txt`와 이용약관을 확인합니다.
- 개인 학습/포트폴리오 용도는 상대적으로 리스크가 낮지만,
  배포하거나 수익화(광고, 유료 구독 등)를 고려한다면
  각 매체와의 라이선스/제휴 여부를 반드시 검토해야 합니다.
- RSS를 제공하는 매체는 해당 매체의 RSS 이용 정책을 우선 확인합니다.
